# OpenEmbedded/Yocto Project BSP Layer for Third-Party NXP-Based Boards

This layer provides support for boards built around NXP's i.MX and Layerscape
SoCs by third-party vendors, for use with OpenEmbedded and/or the Yocto
Project. It builds on [meta-freescale](https://github.com/Freescale/meta-freescale),
which provides the SoC support, the NXP reference boards and the shared BSP
components.

## Supported Machines

- **Boundary Devices:** nitrogen6x, nitrogen6x-lite, nitrogen6sx, nitrogen7,
  nitrogen8m, nitrogen8mm, nitrogen8mn, nitrogen8mp
- **Kontron:** imx6ul-kontron
- **Olimex:** imx233-olinuxino-{maxi,micro,mini,nano}, olimex-imx8mp-evb
- **SolidRun:** cubox-i, lx2160acex7
- **TechNexion:** imx6qdl-pico, imx6ul-pico, imx7d-pico
- **Variscite:** imx6qdl-variscite-som
- **Others:** imx6dl-riotboard, imx6sl-warp, imx7s-warp, wandboard

See `conf/machine/*.conf` for each board's description.

## Quick Start

Add the layer and its dependencies to an existing build directory, select a
machine and build an image:

```sh
bitbake-layers add-layer ../meta-freescale ../meta-freescale-3rdparty
echo 'MACHINE = "wandboard"' >> conf/local.conf
bitbake core-image-minimal
```

## NXP End User License Agreement

Some components shipped by meta-freescale, such as the boot and DDR firmware,
are distributed by NXP under the NXP Software License Agreement, and their
recipes fail to build until it is accepted. The i.MX 8M machines in this layer
need it even for a minimal image. See
[meta-freescale's EULA section](https://github.com/Freescale/meta-freescale#nxp-end-user-license-agreement)
for how to accept it.

## Contributing

Please submit any patches against the `meta-freescale-3rdparty` layer by using
the GitHub pull-request feature. Fork the repo, create a branch, do the work,
rebase from upstream, and then create the pull request.

Follow the
[Yocto Project Contributor Guide](https://docs.yoctoproject.org/contributor-guide/submit-changes.html)
for commit messages: prefix the subject with the recipe or component name, add
a `Signed-off-by` line, and mark every recipe patch with an `Upstream-Status`.
Pull requests are checked with [oelint-adv](contrib/oelint).
